# 학제 간 융합도 지표 구현 및 통합 안내

## 1. 담당 기능 및 구현 내용

- 담당자: 윤성원
- 담당 지표: 학제 간 융합도
- 구현 파일: `interdisciplinarity.py`
- 데이터 파일: `mock-up-data-interdisciplinarity-demo.json`
- 사용 언어 및 도구: Python, Streamlit, Plotly

연구실 2곳의 학제 간 융합도와 분야 분류율을 계산하고, 최근 5년간 연구 분야의 비중 변화를 생키 다이어그램(Sankey Diagram)으로 시각화하도록 구현함.

현재 팀 공통 Mock JSON을 확장한 가상 데이터로 Streamlit 실행 및 화면 출력까지 확인.

## 2. 팀 공통 JSON 수정 이유 및 추가 사항

학제 간 융합도 계산에는 **논문별 연구 분야 분류 정보**가 필요하기 때문에 기존 데이터만으로는 정확한 지표 계산이 어려우므로,

기존 JSON의 `lab_A`, `lab_B` 구조와 다른 지표 관련 데이터는 유지하고, 각 연구실에 `interdisciplinarity_demo_papers` 필드만 추가함.

추가 필드 구성:

- `id`: 논문별 고유 식별자
- `year`: 논문 발표 연도
- `field_ids`: 논문이 속하는 연구 분야 목록

한 논문에 여러 분야를 부여할 수 있으며, 분야 정보가 없는 경우 빈 배열(`[]`)로 표시

## 3. 핵심 지표 계산식

**① 학제 간 융합도(%)**

\= 2개 이상 연구 분야로 분류된 논문 수 ÷ 분야가 1개 이상 분류된 논문 수 × 100

- 분야가 2개 이상인 논문을 다분야 논문으로 계산
- 분야가 분류되지 않은 논문은 융합도 계산의 분모에서 제외
- 융합도는 분류된 논문 중 여러 분야에 걸친 논문의 비율을 의미

**② 분야 분류율(%)**

\= 분야가 1개 이상 분류된 논문 수 ÷ 분석에 사용한 전체 표본 논문 수 × 100

- 분석에 포함한 논문 중 분야 정보가 제공된 비율을 확인하는 보조 지표

**③ 연구 분야별 비중(%)**

\= 해당 분야에 배분된 논문 가중치 합계 ÷ 분야가 분류된 논문 수 × 100

- 논문이 여러 분야에 속하면 각 분야에 동일한 가중치로 나누어 계산
- 예: 한 논문이 2개 분야에 속하는 경우 각 분야에 0.5편씩 배분

가상 표본 기준 계산 결과:

- DIML: 융합도 50.0%(4/8편), 분류율 88.9%(8/9편)
- CV Lab: 융합도 16.7%(1/6편), 분류율 85.7%(6/7편)

※ 기존 공통 JSON의 전체 논문 수 67편/30편은 위 융합도 계산의 분모가 아님. 현재 수치는 추가된 가상 표본에서 계산한 결과

## 4. 화면 시각화 및 구현 결과

- 연구실별 학제 간 융합도·분야 분류율·표본 논문 수 표시
- 비교 기준연도 선택 기능
- 최근 5년을 초기 3년과 최근 2년으로 구분
- 두 기간의 연구 분야별 비중을 생키 다이어그램으로 시각화
- 분야별 비중 비교표 및 데이터 해석 주의 안내 제공

생키 다이어그램은 두 기간에 같은 연구 분야가 차지하는 비중을 연결하고, 비중의 증가·감소를 별도로 표시

단, 논문이나 연구자가 실제로 다른 학문 분야로 이동했다는 것을 의미하지는 않음.

## 5. 파일 통합 시 주의사항

**① JSON 구조 유지**

- 기존 팀 공통 JSON의 `lab_A`, `lab_B` 구조 유지
- 각 연구실의 `interdisciplinarity_demo_papers` 필드를 추가하여 사용
- 기존 논문·산학협력 관련 필드의 이름과 값은 변경하지 않음

**② Python 함수 통합**

- 메인 함수: `render_interdisciplinarity(data)`
- 입력값: JSON에서 읽어온 Python 딕셔너리
- 다른 Python 파일에서 해당 함수를 import하여 호출 가능
- 함수 내부에서 Streamlit 화면을 렌더링함

**③ 실제 OpenAlex 데이터 연동**

실제 API 연동 시에는 다음 정보를 확보해야 함.

- 논문별 고유 ID
- 논문 발표 연도
- 논문별 연구 분야 분류 정보
- 연구실 소속 논문 여부

분야 분류는 동일한 분류 체계와 계층을 사용해야 하며, 논문 ID 기준 중복 제거가 필요

**④ 데이터 부족 및 해석 유의사항**

- 분야가 분류된 논문이 없으면 융합도 산출 불가
- 현재 데모에서는 분류 논문 10편 미만 또는 분류율 70% 미만인 경우 해석 주의 표시
- 연구 분야 분류 비율이 높아도 학생의 전공 적합성이나 실제 연구실 생활을 직접 평가하는 지표는 아님
- 데이터 수집 누락, 연구실 식별 및 분야 분류 기준에 따라 결과가 달라질 수 있음

## 6. VS Code 실행 방법 및 필요 패키지

실행 환경:

- Python
- Streamlit (웹사이트 화면 구현)
- Plotly (생키 다이어그램 시각화)

최초 실행 시 VS Code 터미널에서 다음 명령어를 순서대로 실행.

① 가상환경 생성

`python3 -m venv .venv`

② 가상환경 활성화 (macOS)

`source .venv/bin/activate`

③ 필요 패키지 설치

`python -m pip install "streamlit>=1.51,<2" "plotly>=6,<7"`

④ Streamlit 웹사이트 실행

`python -m streamlit run interdisciplinarity.py`

**Windows (PowerShell) 실행 방법**

① 가상환경 생성

`py -m venv .venv`

② 가상환경 활성화 (Windows PowerShell)

`.\.venv\Scripts\Activate.ps1`

③ 필요 패키지 설치

`python -m pip install "streamlit>=1.51,<2" "plotly>=6,<7"`

④ Streamlit 웹사이트 실행

`python -m streamlit run interdisciplinarity.py`

※ 단독 실행 시 Python 파일과 확장 JSON 파일을 같은 폴더에 배치해야함.

※ 기존 Python 가상환경에 해당 패키지가 설치되어 있으면 매번 재설치할 필요는 없음.

※ 함수를 메인 웹사이트에 통합하는 경우에는 개별 Streamlit 실행 명령어 대신 메인 앱에서 함수를 import하여 사용 가능
